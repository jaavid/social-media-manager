# مدیریت داخلی جنگو

فرانت‌اند مسیر اصلی کار روزانه، ساخت پست، تأیید، انتشار و پاسخ به مخاطبان است.
پنل جنگو در `/backend/` برای مدیریت اطلاعات و تنظیمات و بررسی گزارش‌های عملیاتی
در دسترس است. مسیر `/admin/` متعلق به فرانت‌اند است.

پنل داخلی فارسی و راست‌به‌چپ است. مدل‌ها، فیلدها، وضعیت‌ها و گروه‌های فرم‌های
ثبت‌شده عنوان فارسی دارند. زبان عمومی API تغییری نمی‌کند.

## امکانات مدیریت

| بخش | امکانات |
| --- | --- |
| فضای کاری | اطلاعات تماس و برند، مالکیت، اشتراک، قابلیت‌ها، تنظیمات ربات و توقف پردازش |
| کاربران و اتصال‌ها | پروفایل، نقش، فضای کاری، حساب اجتماعی و اطلاعات اتصال پلتفرم |
| محتوای سایت و داده‌های مرجع | ویرایش محتوا، مجموعه‌ها و گزینه‌های هر مجموعه |
| رسانه‌ها | مدیریت فایل، متن جایگزین، پوشه و برچسب‌ها |
| صف انتشار و خودکارسازی | مدیریت تنظیمات صف، قانون‌ها و فعال یا غیرفعال کردن آن‌ها |
| گفتگوها | تعیین مسئول، برچسب‌گذاری، ستاره‌دار کردن، بایگانی و ثبت رسیدگی |
| پست یکپارچه، گزارش انتشار، آیتم صف، پیام و نظر مشتری | مشاهده، جستجو و فیلتر؛ تغییر وضعیت، ارسال و پاسخ از فرانت‌اند انجام می‌شود |

ورود نیازمند حساب فعال با `is_staff=True` است. کاربران کارکنان باید مجوز مدل
مربوط را نیز داشته باشند. برای مدل‌های عملیاتی فقط مشاهده مجاز است؛ حتی مدیر کل
نمی‌تواند از پنل جنگو رکورد جدید بسازد، وضعیت انتشار را تغییر دهد یا آن‌ها را حذف کند.

## اعمال تغییرات

از پوشه `backend` اجرا کنید:

```sh
python manage.py migrate
```

مایگریشن `0074_persian_admin_labels` عنوان‌ها، توضیحات و برچسب‌های گزینه‌ها را
تکمیل می‌کند. نام جدول‌ها و فیلدها، کلیدهای API و مقادیر ذخیره‌شده گزینه‌ها ثابت
می‌مانند. مقادیر JSON همچنان با کلیدهای فنی فعلی وارد می‌شوند؛ نمونه‌ها در راهنمای
فیلدهای مرتبط آمده‌اند.
